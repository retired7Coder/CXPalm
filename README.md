# CXPalm

**把电脑上的 Codex，带到手机和浏览器。**

离开电脑，也能查看任务进度、继续对话、发送文件和处理审批。CXPalm 为官方 Codex
桌面提供一个由你自己管理的远程入口：电脑继续执行，手机和网页随时连接。

Web / Android / 桌面网关 **0.0.11 / build13** · 独立项目，非 OpenAI 官方产品。

[下载安装包](https://github.com/retired7Coder/CXPalm/releases) · [部署指南](deploy/README.md) · [功能一览](#主要功能)

也不会为此另开模型请求。模型、权限与上下文用量直接显示在输入框上方同一行；百分比表示上下文占用，不是账户剩余额度。
2026-11-07 已继续核对原生缓存、通知与只读快照，详见[接口核验记录](docs/NATIVE-COMPOSER-PREDICTIONS.md)。

引导消息绑定点击时的会话和任务轮次；任务已切换时明确拒绝，保留草稿供核对后手动重试。
请同时更新客户端与网关到 build7 或以上。新引导记录固定显示位置，原生回显沿用同一显示身份；
「我的问题」可分别定位同一轮中的多条引导。旧记录没有保存的位置不会凭空补写。

返回文件：Codex 输出的本地文件引用和文档链接会显示为文件卡片。网页点击下载，Android
选择保存位置；Excel、PDF、HTML 等下载后用对应应用打开。文件须仍在原电脑的允许目录中，
每个文件最多 20 MiB，需要保持网关连接及有效授权。HTML 作为文件下载，不在会话页执行脚本。

图片与文档缓存（build13）：图片预览与大图共用下载内容，重复下载文档也可复用本地副本，
支持刷新网页或重启 App 后继续使用缓存。每次复用仍需原电脑在线确认授权、原文件及其内容版本，
未变化时只返回确认，不重传文件；原文件更新后重新下载，文件被删除或授权失效时不会返回旧副本。
缓存按电脑、授权及会话来源隔离，最多保留 64 MiB、24 项、7 天，Android 私有缓存使用加密存储。
可在 Web / App「设置 → 图片与文档缓存」清理，不删除聊天、草稿或用户已导出的文件。

更新提示：GitHub 账号已更名为 `retired7Coder`，仓库 ID 与所有者 ID 均未改变。
build11 及更早版本的桌面/App 自动下载会拒绝这次账号改名跳转，首次请从发布页手动覆盖安装新版，
无需卸载或清除数据。build13 只放行到同一仓库新账号名的原路径跳转，继续核验下载哈希、包名及签名。

审批支持：网页与 App 可处理命令执行、文件变更、权限请求及 MCP 工具调用确认；权限批准仅限本轮、仅授予请求列出的范围。登录、身份验证、需填写内容的表单及其他类型仍需在官方桌面处理，结果未知时不会自动重发。

会话提醒由本机网关管理，不依赖官方账号或 `auth.json`，切换官方账号不会重置提醒设置。按会话开启后，已授权的网页和 App 可接收任务完成与待审批提醒；官方跨端已读同步单独判断是否可用。

网页和 Android 新建会话可沿用上次新建会话的通知、模型、推理等级和权限模式，
按当前电脑、当前客户端分别记忆。只从已连接的官方桌面状态更新默认值，不复制聊天内容或审批授权；
可取消沿用，完全访问仍需每次确认。设置由原官方桌面接管后应用，未确认时提示核对，不自动重发。

已读状态以官方桌面为准，网页与 App 不再维护另一套覆盖状态，也不读取 `auth.json`。看到最新回复后请求桌面标为已读，收到桌面确认后同步展示；桌面尚未提供同步上下文或结果未确认时不会提前清除未读。运行时安全版本与独立环境核查见[安全维护说明](docs/RUNTIME-SECURITY.md)。

## 为什么使用 CXPalm

- **继续同一个会话**：在手机、网页与电脑之间切换，不必复制对话，也不另开执行器接管主会话。
- **远程入口自己掌握**：网关运行在自己的电脑，域名、HTTPS 入口和连接线路由自己选择与管理。
- **访问权限可控**：账号登录、可撤销的设备授权，以及可选的 IP / 网段白名单。
- **适应自己的网络环境**：可通过自有 HTTPS 反向代理和 SSH 隧道连接，便于按国内或其他复杂网络环境选择合适的部署线路。

这里的“本地运行”指网关和会话控制运行在你的电脑上，不是本地离线模型。
模型调用、官方账号与相关服务仍由官方 Codex 客户端处理；远程访问需要电脑在线，
连接效果取决于实际网络和部署条件。

## 主要功能

| 功能 | 说明 |
| --- | --- |
| 会话管理 | 按项目分组、搜索、新建、重命名、已归档历史只读查看（归档状态请在官方桌面更改） |
| 远程对话 | 发送消息、引导任务、停止、审批，以及消息排队与取消 |
| 模型与任务控制 | 模型、推理强度、Skill、权限、Plan / Goal 和上下文用量 |
| 历史阅读 | 分页历史、问题导航、共享已读、Markdown、代码与折叠工具输出 |
| 图片与文件 | 上传附件、查看会话图片与生成图片；网页支持粘贴和拖放 |
| 会话提醒 | 按会话开启任务完成、待审批提醒，默认关闭 |
| 多端连接 | 多台电脑切换、记住登录、离线只读缓存与应用内更新 |

CXPalm 是 Codex 会话的远程控制入口，不是通用远程桌面，不提供任意终端或文件浏览。

## 开始使用

1. **启动电脑端**：在自己的电脑打开官方 Codex 桌面和 CXPalm 桌面网关。
2. **配置连接**：设置自己的 HTTPS 入口；需要跨网络连接时，可使用自有反向代理与 SSH 隧道。
3. **设置账号**：在 CXPalm 桌面端创建登录账号和密码，没有默认账号或公开注册入口。
4. **连接手机或网页**：浏览器访问自己站点的 `/cxpalm/`，或在 Android App 中填写 HTTPS 地址并登录。
5. **选择会话**：继续对话、查看进度，按需开启会话提醒或配置 IP 白名单。

首次部署请参考 [部署指南](deploy/README.md) 与 [配置示例](deploy/cxpalm.example.json)。

桌面退出、托盘消失及启动异常的本地日志说明见 [故障诊断](docs/DIAGNOSTICS.md)。

## 部署与访问控制

电脑负责执行任务，HTTPS 入口负责将已授权的远程连接转发到本机网关：

```text
手机 / 网页 → 自有 HTTPS 入口 → 本机 CXPalm 网关 → 官方 Codex 桌面
```

- **本地监听**：网关只绑定回环地址，不直接将本机监听端口暴露到公网。
- **自主部署**：远程代理和隧道由自己配置；不要求把远程控制交给额外的公共托管平台。
- **设备授权**：可在桌面端撤销设备；更改登录账号密码会撤销已有登录授权。
- **可选白名单**：限制允许访问的 IP 或网段，只作用于 CXPalm API，不修改系统防火墙。隧道模式须先配置可信代理的真实 IP 转发。

请妥善保护自己的服务器、登录凭据和设备。具体信任边界见 [安全说明](SECURITY.md)。

## 更新与维护

桌面端“设置 → 启动，由你决定”可开启“启动后自动最小化到托盘”，下次打开或重启 App 生效。该选项不改变网关自启动；首次配置或启动失败仍显示窗口，点击托盘或再次打开 App 可恢复主窗口。

Android 与桌面端从本仓库的更新清单检查版本，并从 [GitHub Releases](https://github.com/702165405/CXPalm/releases)
下载安装包，由用户确认安装；网页更新由部署者发布。更新会校验下载来源、文件哈希及应用身份，
只允许当前仓库的发布路径和对应 GitHub 下载服务跳转。自建分发需配置自己的仓库更新源，
与登录服务器地址分开管理，详见 [部署指南](deploy/README.md)。

版本变化见 [变更记录](CHANGELOG.md)。反馈问题时请提供版本、操作系统与复现步骤，
不要附带登录凭据、真实聊天内容或完整运行日志。构建、测试和贡献方式见 [贡献指南](CONTRIBUTING.md)。

本版本线从 `0.0.1 / build1` 开始，Android 安装构建号也从 1 起步，之后与桌面构建号同步递增。
已有更高构建号的旧 App 无法直接覆盖降级；不会关闭系统降级或签名保护，也不会自动卸载 App。
手动切换前请自行妥善保留本机需要的数据；桌面配置、授权和服务器数据不需要因此清空。

CXPalm 依赖官方桌面的会话接口，官方客户端升级可能需要适配。浏览器关闭或手机
系统停止后台进程后，提醒不保证送达；使用边界与验证状态见相关文档。
